# Карточки — PWA для интервального повторения

Офлайн-приложение для изучения карточек (личный аналог Quizlet): наборы, режим
«Карточки», режим «Учить» с алгоритмом SM-2, тесты и статистика. Без фреймворков,
без сборки, без внешних зависимостей — GitHub Pages отдаёт файлы как есть.

На iPhone ставится через Safari → «Поделиться» → «На экран „Домой"», после чего
работает в офлайне и открывается без адресной строки.

## Возможности

| Раздел | Что умеет |
| --- | --- |
| Наборы | создать, переименовать, удалить, сбросить прогресс |
| Карточки | добавить/изменить/удалить, поиск, необязательное изображение |
| Импорт | вставить список строк: `термин - определение`, `термин[TAB]определение`, `термин = определение`, `термин: определение` |
| Экспорт | тот же текстовый формат (через тире или табуляцию): копирование или файл `.txt` |
| Карточки (режим) | переворот по тапу, свайп влево/вправо, прогресс сессии, повтор сложных |
| Учить | только карточки со сроком «на сегодня», оценки «снова / трудно / хорошо / легко» с предпросмотром интервала |
| Тест | выбор из 4 вариантов и ввод ответа (регистр, «ё» и пунктуация игнорируются) |
| Статистика | выучено / изучаю / новые, повторения за 14 дней, серия дней, разбивка по наборам |
| Данные | IndexedDB, резервная копия в JSON и восстановление |

## Деплой на GitHub Pages

1. Инициализировать репозиторий и сделать коммит:

   ```bash
   git init
   git add .
   git commit -m "Карточки: PWA"
   ```

2. Создать репозиторий на GitHub и запушить:

   ```bash
   git remote add origin https://github.com/<username>/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```

3. В настройках репозитория → **Settings → Pages → Build and deployment**:
   * **Source**: `Deploy from a branch`
   * **Branch**: `main`, папка `/ (root)` — сохранить.

4. Через 1–2 минуты приложение доступно по адресу
   `https://<username>.github.io/<repo-name>/`.

   Все пути в проекте относительные, поэтому подпапка репозитория работает без правок.

5. На iPhone: открыть эту ссылку **в Safari** → кнопка «Поделиться» →
   **«На экран „Домой"»** → «Добавить». Приложение появится иконкой на домашнем
   экране, запустится в полноэкранном режиме и будет работать без сети.

> Chrome/Firefox на iOS установить PWA не могут — нужен именно Safari.

## Обновление приложения

Service worker кэширует статику по стратегии cache-first, поэтому **после правок
кода нужно поднять версию кэша**: в `service-worker.js` изменить

```js
var CACHE_VERSION = 'v1.0.0';   // → 'v1.0.1'
```

При следующем запуске старый кэш удаляется, файлы перезагружаются, вкладка
обновляется сама. Внутри приложения то же самое делает кнопка
**Статистика → «Проверить обновление»**.

## Локальный запуск

Service worker и IndexedDB не работают по `file://`, нужен http-сервер:

```bash
python3 -m http.server 8000
# или: npx http-server -p 8000 -c-1
```

Затем открыть `http://localhost:8000/`.

## Данные

Всё хранится локально в IndexedDB (`flashcards`), сеть не используется вообще.

| Хранилище | Поля |
| --- | --- |
| `decks` | `id`, `name`, `createdAt`, `updatedAt`, `cardIds[]` |
| `cards` | `id`, `deckId`, `term`, `definition`, `image`, `createdAt` |
| `progress` | `cardId`, `interval`, `easeFactor`, `repetitions`, `lapses`, `dueDate`, `lastReviewed` |
| `reviews` | журнал повторений по дням (для статистики) |

Изображения сжимаются до 900 px и хранятся как data URL внутри карточки.

Safari может очистить хранилище сайта, который давно не открывали, поэтому
приложение запрашивает `navigator.storage.persist()`, а в статистике есть
кнопка «Сохранить» — резервная копия всей базы в JSON.

## Алгоритм повторения (SM-2)

Оценка пользователя переводится в качество ответа `q`: снова → 2, трудно → 3,
хорошо → 4, легко → 5. Коэффициент лёгкости пересчитывается стандартной формулой
SM-2:

```
EF' = EF + (0.1 − (5 − q) × (0.08 + (5 − q) × 0.02)),   EF ≥ 1.3
```

Интервалы — расписание SM-2 (1 день → 6 дней → `interval × EF`) с поправками
как в Anki: «трудно» — ×1.2, «легко» — ×EF×1.3, «снова» обнуляет серию,
увеличивает счётчик провалов и возвращает карточку в текущую сессию.
`dueDate = сегодня + interval`, в режим «Учить» попадают только карточки с
`dueDate <= сегодня`. Выученной считается карточка с интервалом больше 21 дня.

Режим «Карточки» тоже влияет на расписание: «помню» = «хорошо», «не помню» =
«снова». Тест на расписание не влияет — это просто самопроверка.

## Что можно улучшить дальше

* Обратные карточки (определение → термин) и режим «Пишу» в обучении.
* Ограничение новых карточек в день и «зарывание» родственных карточек.
* Синхронизация между устройствами (сейчас данные живут только на устройстве).
* Озвучка терминов через `SpeechSynthesis` и импорт из CSV/Anki-колод.
* Более точный алгоритм (FSRS) вместо SM-2.
